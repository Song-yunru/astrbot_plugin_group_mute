# 群聊静音

自动发现机器人所在的群聊，并让机器人在选定群聊里**完全不出声**。

## 安装

在 AstrBot 面板的插件页填入仓库地址，或直接把本目录放进 `data/plugins/`：

```
https://github.com/Song-yunru/astrbot_plugin_group_mute
```

插件无额外依赖，装上后重启 AstrBot 即可，面板「插件 → 群聊静音」会多出一个页面。

## 功能

- **自动检测群聊**：机器人每收到一条群消息，就记录群号与群名（可在页面里看到）。
- **页面开关**：AstrBot 面板 → 插件 → 群聊静音，勾选即生效，实时保存。
- **指令控制**：在群里发 `群静音` 切换本群状态；`静音列表` 查看所有静音群；`群聊列表` 查看已记录的群。
- 静音后：**连 @ 也不回**（可在配置里改成"被 @ 时仍回复"）。

## 配置

| 项 | 说明 |
|---|---|
| `muted_groups` | 预置静音群号，逗号或换行分隔，启动时生效 |
| `reply_when_mentioned` | 开启后静音群里被 @ 仍会回复 |
| `record_groups` | 是否记录群消息用于列表 |

## 数据

状态保存在 `data/plugin_data/astrbot_plugin_group_mute/state.json`。

## 注意

- 静音是**在事件层面终止**的，所以不会触发任何插件、也不会调用大模型。
- 解除静音：页面里关掉开关，或在群里发 `群静音`（需要 @ 或唤醒词）。
